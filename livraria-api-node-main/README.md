# semana9-desenvolvimento-api-backend

## Documentação OpenAPI 3.0 (Swagger UI)

### Como executar a API

```bash
cd livraria-api-node-main
npm install
npm start
```

### Rotas de Documentação Disponíveis

- **Interface Interativa (Swagger UI)**:
  - `http://localhost:3000/docs`
  - `http://localhost:3000/api/docs`
  - `http://localhost:3000/docs/api`
- **Especificação OpenAPI 3.0 Bruta (JSON)**:
  - `http://localhost:3000/docs/api.json`
  - `http://localhost:3000/api-docs.json`
  - `http://localhost:3000/api/docs.json`
